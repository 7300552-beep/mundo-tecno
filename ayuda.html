¿Necesitas más soporte?

El servidor no responde o hay latencia alta

Para solucionarlo puedes:

  • Verificar el estado de las interfaces de red con el comando ping.
  • Reiniciar el daemon del servicio de enrutamiento.
  • Comprobar si existe un ataque DDoS en curso desde el panel de monitoreo.
Fallo en la autenticación / Contraseña bloqueada

Para solucionarlo puedes:

  • Solicitar un token de recuperación a tu administrador del sistema.
  • Esperar 15 minutos para que el bloqueo por intentos expire.
  • Ingresar mediante la consola serial SSH con credenciales root.
Certificado de seguridad SSL expirado

Para solucionarlo puedes:

  • Ejecutar el script automático certbot renew en el servidor web.
  • Verificar que las claves públicas estén apuntando al dominio correcto.
